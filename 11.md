## 11. How do you filter data using IN, BETWEEN, LIKE, and comparison operators?

SQL provides several operators for filtering rows in the `WHERE` clause.

The most common ones are:

* **Comparison operators** → compare values
* **`IN`** → match against a list of values
* **`BETWEEN`** → filter within a range
* **`LIKE`** → pattern matching, mainly for text

Assume we have an `employees` table:

| id | name  | department | salary |
| -: | ----- | ---------- | -----: |
|  1 | Sahil | IT         |  50000 |
|  2 | Rahul | HR         |  35000 |
|  3 | Priya | IT         |  65000 |
|  4 | Ankit | Sales      |  45000 |
|  5 | Neha  | HR         |  55000 |

---

# 1. Comparison Operators

Comparison operators compare one value with another.

| Operator         | Meaning                  |
| ---------------- | ------------------------ |
| `=`            | Equal to                 |
| `<>` or `!=` | Not equal to             |
| `>`            | Greater than             |
| `<`            | Less than                |
| `>=`           | Greater than or equal to |
| `<=`           | Less than or equal to    |

### Examples

Employees earning more than ₹50,000:

```sql
SELECT *
FROM employees
WHERE salary > 50000;
```

Employees in the IT department:

```sql
SELECT *
FROM employees
WHERE department = 'IT';
```

Employees earning ₹50,000 or less:

```sql
SELECT *
FROM employees
WHERE salary <= 50000;
```

### Combining conditions

You can use `AND`, `OR`, and `NOT`.

```sql
SELECT *
FROM employees
WHERE department = 'IT'
  AND salary > 50000;
```

This means both conditions must be true.

---

# 2. `IN`

`IN` checks whether a value matches **any value in a specified list**.

Instead of writing:

```sql
SELECT *
FROM employees
WHERE department = 'IT'
   OR department = 'HR'
   OR department = 'Sales';
```

you can write:

```sql
SELECT *
FROM employees
WHERE department IN ('IT', 'HR', 'Sales');
```

This is cleaner and easier to maintain.

### `NOT IN`

To exclude values:

```sql
SELECT *
FROM employees
WHERE department NOT IN ('HR', 'Sales');
```

This returns employees whose department is neither HR nor Sales.

### Important `NULL` caveat

Be careful with `NOT IN` if the list or compared column can involve `NULL`. SQL's three-valued logic can produce unexpected results.

For example, if you specifically want rows where a column is not `NULL`, use:

```sql
WHERE department IS NOT NULL
```

rather than trying to handle it with `NOT IN`.

---

# 3. `BETWEEN`

`BETWEEN` checks whether a value falls within a range.

For example, employees earning between ₹40,000 and ₹60,000:

```sql
SELECT *
FROM employees
WHERE salary BETWEEN 40000 AND 60000;
```

### Important: `BETWEEN` is inclusive

It includes both boundaries.

So:

```sql
BETWEEN 40000 AND 60000
```

means:

```text
salary >= 40000
AND
salary <= 60000
```

Therefore, salaries of exactly ₹40,000 and ₹60,000 are included.

### `NOT BETWEEN`

```sql
SELECT *
FROM employees
WHERE salary NOT BETWEEN 40000 AND 60000;
```

---

# 4. `LIKE`

`LIKE` is used for **pattern matching**, especially with text.

It uses wildcard characters.

### `%` wildcard

`%` means **zero or more characters**.

Find employees whose name starts with `S`:

```sql
SELECT *
FROM employees
WHERE name LIKE 'S%';
```

Matches:

```text
Sahil
Sanjay
Simran
```

Find names ending with `a`:

```sql
WHERE name LIKE '%a';
```

Find names containing `ah`:

```sql
WHERE name LIKE '%ah%';
```

---

### `_` wildcard

`_` represents **exactly one character**.

For example:

```sql
WHERE name LIKE 'S_hil';
```

can match:

```text
Sahil
```

because `_` represents the single character `a`.

Compare:

```text
%  → zero or more characters
_  → exactly one character
```

### `NOT LIKE`

You can also exclude a pattern:

```sql
SELECT *
FROM employees
WHERE name NOT LIKE 'S%';
```

---

# Combining Different Filters

These operators are often combined.

For example, find IT or HR employees earning between ₹40,000 and ₹70,000:

```sql
SELECT name, department, salary
FROM employees
WHERE department IN ('IT', 'HR')
  AND salary BETWEEN 40000 AND 70000;
```

Another example:

Find employees whose names start with `S` and whose salary is greater than ₹40,000:

```sql
SELECT name, salary
FROM employees
WHERE name LIKE 'S%'
  AND salary > 40000;
```

## Quick Comparison

| Operator        | Purpose                   | Example                            |
| --------------- | ------------------------- | ---------------------------------- |
| `=`           | Exact match               | `salary = 50000`                 |
| `>`           | Greater than              | `salary > 50000`                 |
| `<`           | Less than                 | `salary < 50000`                 |
| `>=`          | Greater/equal             | `salary >= 50000`                |
| `<=`          | Less/equal                | `salary <= 50000`                |
| `<>` / `!=` | Not equal                 | `department <> 'HR'`             |
| `IN`          | Match any value in a list | `department IN ('IT', 'HR')`     |
| `BETWEEN`     | Match a range             | `salary BETWEEN 40000 AND 60000` |
| `LIKE`        | Match a text pattern      | `name LIKE 'S%'`                 |
| `NOT IN`      | Exclude listed values     | `department NOT IN ('HR')`       |
| `NOT LIKE`    | Exclude a pattern         | `name NOT LIKE 'S%'`             |

## Common Interview Traps

### 1. `BETWEEN` includes both boundaries

```sql
WHERE salary BETWEEN 40000 AND 60000
```

means:

```sql
salary >= 40000 AND salary <= 60000
```

### 2. Don't use `= NULL`

This is incorrect:

```sql
WHERE department = NULL;
```

Use:

```sql
WHERE department IS NULL;
```

Similarly:

```sql
WHERE department IS NOT NULL;
```

### 3. `LIKE` is for pattern matching

```sql
WHERE name LIKE 'S%'
```

doesn't mean "name equals S." It means **name starts with S**.

### 4. `IN` is cleaner than repeated `OR`

Instead of:

```sql
WHERE department = 'IT'
   OR department = 'HR'
   OR department = 'Sales'
```

prefer:

```sql
WHERE department IN ('IT', 'HR', 'Sales')
```

when you're checking membership in a fixed set.

---

### Interview Takeaway

Think of them like this:

> **Comparison operators → compare values**
> **`IN` → choose from a list**
> **`BETWEEN` → choose from a range**
> **`LIKE` → match a text pattern**

And all of them are commonly used inside the **`WHERE` clause to filter row**

Aggregate functions compute one value from many rows. Common examples are `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`.

```sql
SELECT COUNT(*) AS total_users, AVG(salary) AS avg_salary
```

Aggregate functions are essential for reporting and analytics, especially with `GROUP BY` and `HAVING`.
