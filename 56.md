## 56. Find the second-highest salary.

### Answer

There are several ways to find the second-highest salary. The important question is whether **duplicate salaries should count as the same salary**.

Suppose:

```text
employees
+----+--------+--------+
| id | name   | salary |
+----+--------+--------+
| 1  | Rahul  | 90000  |
| 2  | Amit   | 80000  |
| 3  | Priya  | 80000  |
| 4  | Neha   | 70000  |
+----+--------+--------+
```

The second-highest **distinct salary** is `80000`.

---

### 1. Using `DENSE_RANK()` — recommended for interviews

```sql
WITH ranked AS (
    SELECT
        name,
        salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM employees
)
SELECT name, salary
FROM ranked
WHERE salary_rank = 2;
```

Result:

```text
Amit   80000
Priya  80000
```

`DENSE_RANK()` is useful because employees with the same salary receive the same rank.

```text
90000 → rank 1
80000 → rank 2
80000 → rank 2
70000 → rank 3
```

---

### 2. Using `MAX()`

If you only need the **salary value**:

```sql
SELECT MAX(salary) AS second_highest_salary
FROM employees
WHERE salary < (
    SELECT MAX(salary)
    FROM employees
);
```

The inner query finds the highest salary:

```text
90000
```

Then the outer query looks for the maximum salary below it:

```text
80000
```

---

### 3. Using `DISTINCT`, `ORDER BY`, and `OFFSET`

In PostgreSQL:

```sql
SELECT DISTINCT salary
FROM employees
ORDER BY salary DESC
LIMIT 1 OFFSET 1;
```

Explanation:

```text
ORDER BY salary DESC
```

produces:

```text
90000
80000
70000
```

`OFFSET 1` skips the highest salary, and `LIMIT 1` returns the next one.

---

### Important Interview Trap

This query:

```sql
SELECT salary
FROM employees
ORDER BY salary DESC
LIMIT 1 OFFSET 1;
```

does **not necessarily find the second-highest distinct salary**.

With:

```text
90000
80000
80000
70000
```

it could return `80000`, but if the highest salary is duplicated:

```text
90000
90000
80000
```

it would return `90000`, which is not the second-highest **distinct** salary.

So if the question means **second-highest distinct salary**, use `DENSE_RANK()`, `MAX()` with a `< MAX()` condition, or `DISTINCT`.

### Interview Takeaway

> **For the second-highest distinct salary, `DENSE_RANK()` is a robust approach because it handles duplicate salaries correctly. If only the salary value is needed, `MAX()` with a condition below the maximum is also simple and effectiv**

## Answer

`COALESCE` returns the first non-NULL value in a list. `NULLIF` returns `NULL` if two expressions are equal; otherwise it returns the first expression.

```sql
SELECT COALESCE(phone, 'No phone') AS contact,
       NULLIF(score, 0) AS score
FROM users;
```

### Interview takeaway

These functions are useful for writing safer queries and handling missing or default values.
