## 35. How would you find the second-highest salary?

### Answer

There are several ways to find the second-highest salary. In interviews, it's useful to know both the **simple approach** and the **window-function approach**.

Assume:

```text
employees
---------
id
name
salary
```

### 1. Using `MAX()` with a subquery

A straightforward approach is:

```sql
SELECT MAX(salary) AS second_highest_salary
FROM employees
WHERE salary < (
    SELECT MAX(salary)
    FROM employees
);
```

### How it works

The inner query finds the highest salary:

```sql
SELECT MAX(salary)
FROM employees;
```

Then the outer query considers only salaries **less than the highest salary** and finds the maximum among them.

For:

| salary |
| -----: |
| 100000 |
|  90000 |
|  80000 |
|  70000 |

The result is:

```text
90000
```

---

### 2. Using `DENSE_RANK()`

This is especially useful when the question means the **second-highest distinct salary**.

```sql
WITH ranked AS (
    SELECT
        name,
        salary,
        DENSE_RANK() OVER (
            ORDER BY salary DESC
        ) AS salary_rank
    FROM employees
)
SELECT name, salary
FROM ranked
WHERE salary_rank = 2;
```

Suppose:

| name  | salary |
| ----- | -----: |
| Amit  | 100000 |
| Rahul |  90000 |
| Priya |  90000 |
| Neha  |  80000 |

Result:

| name  | salary |
| ----- | -----: |
| Rahul |  90000 |
| Priya |  90000 |

Both employees are returned because `90000` is the **second-highest distinct salary**.

---

### 3. Using `DISTINCT` and `ORDER BY`

If you only need the salary value, PostgreSQL supports:

```sql
SELECT DISTINCT salary
FROM employees
ORDER BY salary DESC
LIMIT 1 OFFSET 1;
```

`OFFSET 1` skips the highest distinct salary, and `LIMIT 1` returns the next one.

---

### Important Interview Trap

Consider:

```text
100000
90000
90000
80000
```

If you use:

```sql
ROW_NUMBER() OVER (ORDER BY salary DESC)
```

the two employees earning `90000` receive different row numbers:

```text
100000 → 1
90000  → 2
90000  → 3
80000  → 4
```

So `ROW_NUMBER()` is generally **not the right choice when you mean the second-highest distinct salary**.

`DENSE_RANK()` handles this naturally:

```text
100000 → 1
90000  → 2
90000  → 2
80000  → 3
```

### Interview Takeaway

If asked **"find the second-highest salary"**, clarify whether they mean:

* **Second-highest distinct salary** → `DENSE_RANK()` or `MAX()` + subquery
* **Second row after sorting** → `ROW_NUMBER()` can be appropriate

A strong interview answer is:

> “I would use `DENSE_RANK()` if duplicate salaries are possible and I need the second-highest distinct salary. If I only need the salary value, `MAX()` with a subquery is also a simple solution

## Answer

A stored procedure is a reusable database routine that encapsulates SQL logic. It can accept parameters and execute a series of statements.

```sql
CREATE PROCEDURE get_orders_by_user(user_id INT)
BEGIN
    SELECT * FROM orders WHERE user_id = user_id;
END;
```

### Interview takeaway

Stored procedures improve reuse and reduce repeated SQL code in application layers.
