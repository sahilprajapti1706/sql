## 13. How do COUNT, SUM, AVG, MIN, and MAX work?

`COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()` are **aggregate functions**. They process multiple rows and return a summarized result.

Assume an `orders` table:

| id | customer | amount |
| -: | -------- | -----: |
|  1 | A        |    500 |
|  2 | B        |    800 |
|  3 | A        |   1200 |
|  4 | C        |    300 |
|  5 | B        |    700 |

---

### 1. `COUNT()`

`COUNT()` counts rows or non-`NULL` values.

#### Count all rows

```sql
SELECT COUNT(*) AS total_orders
FROM orders;
```

Result:

```text
5
```

`COUNT(*)` counts **every row**, including rows containing `NULL` values.

#### Count non-NULL values

```sql
SELECT COUNT(amount) AS orders_with_amount
FROM orders;
```

`COUNT(amount)` counts only rows where `amount` is not `NULL`.

### Important distinction

```sql
COUNT(*)       -- counts rows
COUNT(column)  -- counts non-NULL values in that column
```

---

### 2. `SUM()`

`SUM()` calculates the total of numeric values.

```sql
SELECT SUM(amount) AS total_sales
FROM orders;
```

Calculation:

```text
500 + 800 + 1200 + 300 + 700 = 3500
```

Result:

```text
3500
```

It is commonly used for:

* Total sales
* Total revenue
* Total expenses
* Total quantities

---

### 3. `AVG()`

`AVG()` calculates the arithmetic mean.

```sql
SELECT AVG(amount) AS average_order_value
FROM orders;
```

Calculation:

```text
(500 + 800 + 1200 + 300 + 700) / 5
= 3500 / 5
= 700
```

Result:

```text
700
```

Conceptually:

```text
AVG(column) = SUM(non-NULL values) / COUNT(non-NULL values)
```

So `NULL` values are generally ignored by `AVG()`.

---

### 4. `MIN()`

`MIN()` returns the smallest value.

```sql
SELECT MIN(amount) AS smallest_order
FROM orders;
```

Result:

```text
300
```

It can also work with other comparable data types, depending on the database.

For example:

```sql
SELECT MIN(order_date)
FROM orders;
```

returns the earliest date.

---

### 5. `MAX()`

`MAX()` returns the largest value.

```sql
SELECT MAX(amount) AS largest_order
FROM orders;
```

Result:

```text
1200
```

It can also be used with dates:

```sql
SELECT MAX(order_date)
FROM orders;
```

which returns the latest date.

---

# Using Them with `GROUP BY`

Aggregate functions become especially useful when combined with `GROUP BY`.

For example, calculate order statistics for each customer:

```sql
SELECT
    customer,
    COUNT(*) AS order_count,
    SUM(amount) AS total_spent,
    AVG(amount) AS average_order,
    MIN(amount) AS smallest_order,
    MAX(amount) AS largest_order
FROM orders
GROUP BY customer;
```

Conceptually:

```text
Customer A
   ├── 500
   └── 1200
       ↓
COUNT = 2
SUM   = 1700
AVG   = 850
MIN   = 500
MAX   = 1200

Customer B
   ├── 800
   └── 700
       ↓
COUNT = 2
SUM   = 1500
AVG   = 750
MIN   = 700
MAX   = 800
```

This might produce:

| customer | order_count | total_spent | average_order | smallest_order | largest_order |
| -------- | ----------: | ----------: | ------------: | -------------: | ------------: |
| A        |           2 |        1700 |           850 |            500 |          1200 |
| B        |           2 |        1500 |           750 |            700 |           800 |
| C        |           1 |         300 |           300 |            300 |           300 |

---

## What happens with `NULL`?

Suppose the data is:

| id |   amount |
| -: | -------: |
|  1 |      500 |
|  2 |      800 |
|  3 | `NULL` |

Then:

```sql
SELECT
    COUNT(*) AS row_count,
    COUNT(amount) AS amount_count,
    SUM(amount) AS total,
    AVG(amount) AS average,
    MIN(amount) AS minimum,
    MAX(amount) AS maximum
FROM orders;
```

Conceptually:

```text
COUNT(*)       → 3
COUNT(amount)  → 2
SUM(amount)    → 1300
AVG(amount)    → 650
MIN(amount)    → 500
MAX(amount)    → 800
```

The important point is that most aggregate functions **ignore `NULL` values**.

## Quick Comparison

| Function    | What it answers       | Example             |
| ----------- | --------------------- | ------------------- |
| `COUNT()` | How many?             | Number of orders    |
| `SUM()`   | What is the total?    | Total revenue       |
| `AVG()`   | What is the average?  | Average order value |
| `MIN()`   | What is the smallest? | Smallest order      |
| `MAX()`   | What is the largest?  | Largest order       |

### Interview Takeaway

Remember:

```text
COUNT → quantity
SUM   → total
AVG   → average
MIN   → smallest
MAX   → largest
```

And an important interview distinction:

> **`COUNT(*)` counts rows, while `COUNT(column)` counts only non-`NULL` values in that colum**

## Answer

`WHERE` filters rows before grouping, while `HAVING` filters grouped results after aggregation.

```sql
SELECT department, COUNT(*) AS cnt
FROM employees
GROUP BY department
HAVING COUNT(*) > 5;
```

### Interview takeaway

Use `WHERE` for raw rows and `HAVING` for aggregate-level conditions.
