## 15. What is the difference between `COUNT(*)`, `COUNT(column)`, and `COUNT(DISTINCT column)`?

All three are forms of `COUNT()`, but they answer **different questions**.

Assume this `employees` table:

| id | name  | department |
| -: | ----- | ---------- |
|  1 | Sahil | IT         |
|  2 | Rahul | HR         |
|  3 | Priya | IT         |
|  4 | Ankit | `NULL`   |
|  5 | Neha  | HR         |
|  6 | Amit  | IT         |

---

## 1. `COUNT(*)`

`COUNT(*)` counts **all rows** in the result.

```sql
SELECT COUNT(*) AS total_employees
FROM employees;
```

Result:

```text
6
```

It doesn't matter whether individual columns contain `NULL`.

For example, Ankit's `department` is `NULL`, but his row is still counted.

### Think:

> **"How many rows are there?"**

---

## 2. `COUNT(column)`

`COUNT(column)` counts the number of **non-NULL values** in that column.

```sql
SELECT COUNT(department) AS employees_with_department
FROM employees;
```

There are 5 non-NULL department values:

```text
IT
HR
IT
NULL
HR
IT
```

So the result is:

```text
5
```

The row with `department = NULL` is not counted.

### Think:

> **"How many rows have a value in this column?"**

---

## 3. `COUNT(DISTINCT column)`

`COUNT(DISTINCT column)` counts the number of **unique non-NULL values** in the column.

```sql
SELECT COUNT(DISTINCT department) AS unique_departments
FROM employees;
```

The department values are:

```text
IT
HR
IT
NULL
HR
IT
```

Unique non-NULL values:

```text
IT
HR
```

Therefore:

```text
2
```

### Think:

> **"How many different values are present?"**

---

# Side-by-Side Comparison

For our data:

| Expression                     | What it counts              | Result |
| ------------------------------ | --------------------------- | -----: |
| `COUNT(*)`                   | All rows                    |  `6` |
| `COUNT(department)`          | Non-NULL department values  |  `5` |
| `COUNT(DISTINCT department)` | Unique non-NULL departments |  `2` |

---

## Visual Understanding

```text
Table has 6 rows
        │
        ├── COUNT(*) 
        │      ↓
        │      6
        │
        ├── COUNT(department)
        │      ↓
        │      Ignore NULL
        │      ↓
        │      5
        │
        └── COUNT(DISTINCT department)
               ↓
               Ignore NULL
               Remove duplicates
               ↓
               IT, HR
               ↓
               2
```

---

## Important `NULL` Behavior

`COUNT(*)` and `COUNT(column)` differ mainly when `NULL` is present.

Suppose:

| id | city     |
| -: | -------- |
|  1 | Delhi    |
|  2 | Mumbai   |
|  3 | `NULL` |
|  4 | Delhi    |

Then:

```sql
SELECT COUNT(*) FROM users;
```

returns:

```text
4
```

While:

```sql
SELECT COUNT(city) FROM users;
```

returns:

```text
3
```

And:

```sql
SELECT COUNT(DISTINCT city) FROM users;
```

returns:

```text
2
```

because the unique non-NULL cities are:

```text
Delhi
Mumbai
```

# Practical Examples

### Total number of orders

```sql
SELECT COUNT(*)
FROM orders;
```

Use this when you want the **number of rows/orders**.

### Number of orders with a tracking number

```sql
SELECT COUNT(tracking_number)
FROM orders;
```

Use this when you want to know how many orders have a **non-NULL tracking number**.

### Number of unique customers

```sql
SELECT COUNT(DISTINCT customer_id)
FROM orders;
```

Use this when you want to know **how many different customers placed orders**.

---

## With `GROUP BY`

These functions become particularly useful with grouping.

For example:

```sql
SELECT
    department,
    COUNT(*) AS total_employees,
    COUNT(DISTINCT city) AS unique_cities
FROM employees
GROUP BY department;
```

This can tell you:

> "How many employees are in each department, and how many different cities those employees come from?"

---

## Common Interview Trap

Don't confuse:

```sql
COUNT(*)
```

with:

```sql
COUNT(1)
```

In modern relational databases, `COUNT(1)` is generally also counting rows, so it should not be treated as a magical performance optimization over `COUNT(*)`.

For normal row counting, **`COUNT(*)` clearly communicates your intention**.

---

### Interview Takeaway

Remember the progression:

```text
COUNT(*)                  → How many rows?
COUNT(column)             → How many non-NULL values?
COUNT(DISTINCT column)    → How many unique non-NULL values?
```

For example, with:

```text
IT
HR
IT
NULL
HR
IT
```

the answers are:

```text
COUNT(*)                → 6
COUNT(department)       → 5
COUNT(DISTINCT department) → 2
```

That `NULL` + duplicate behavior is the key thing interviewers usually want you to understan

## Answer

`MIN` and `MAX` return the smallest and largest value in a set of rows. They are often used on numeric, date, or text values.

```sql
SELECT MIN(price) AS cheapest, MAX(price) AS most_expensive
FROM products;
```

### Interview takeaway

These functions are very common in analytics, especially for ranges and thresholds.
