
## 57. Find duplicate records

### Answer

To find duplicate records, the most common approach is **`GROUP BY` + `HAVING COUNT(*) > 1`**.

Suppose we have:

```text
employees
+----+--------+-------------------+
| id | name   | email             |
+----+--------+-------------------+
| 1  | Rahul  | rahul@gmail.com   |
| 2  | Amit   | amit@gmail.com    |
| 3  | Rahul  | rahul@gmail.com   |
| 4  | Priya  | priya@gmail.com   |
+----+--------+-------------------+
```

### 1. Find duplicate values

If `email` should be unique:

```sql
SELECT email, COUNT(*) AS count
FROM employees
GROUP BY email
HAVING COUNT(*) > 1;
```

Output:

```text
email             count
----------------  -----
rahul@gmail.com     2
```

### 2. Find the complete duplicate records

If you want the **actual rows**:

```sql
SELECT *
FROM employees
WHERE email IN (
    SELECT email
    FROM employees
    GROUP BY email
    HAVING COUNT(*) > 1
);
```

Output:

```text
id   name    email
---  ------  ----------------
1    Rahul   rahul@gmail.com
3    Rahul   rahul@gmail.com
```

### 3. Find duplicates based on multiple columns

For example, consider a record duplicate when both `name` and `department` are the same:

```sql
SELECT name, department, COUNT(*) AS count
FROM employees
GROUP BY name, department
HAVING COUNT(*) > 1;
```

The combination of columns is treated as the duplicate key.

### 4. Using `ROW_NUMBER()`

This is particularly useful when you need to identify **which record to keep and which ones are duplicates**:

```sql
WITH duplicates AS (
    SELECT
        *,
        ROW_NUMBER() OVER (
            PARTITION BY email
            ORDER BY id
        ) AS rn
    FROM employees
)
SELECT *
FROM duplicates
WHERE rn > 1;
```

Here:

* `rn = 1` → first record, usually kept
* `rn > 1` → duplicate records

### Interview Takeaway

For a basic interview question, remember:

```sql
SELECT column_name, COUNT(*)
FROM table_name
GROUP BY column_name
HAVING COUNT(*) > 1;
```

**Key idea:** `GROUP BY` creates groups, and `HAVING COUNT(*) > 1` keeps only groups that occur more than once.
