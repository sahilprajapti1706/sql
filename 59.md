## 59. Find the highest-paid employee in each department

### Answer

The cleanest approach is to use a **window function**, especially `DENSE_RANK()`.

```sql
WITH ranked_employees AS (
    SELECT
        name,
        department_id,
        salary,
        DENSE_RANK() OVER (
            PARTITION BY department_id
            ORDER BY salary DESC
        ) AS salary_rank
    FROM employees
)
SELECT
    name,
    department_id,
    salary
FROM ranked_employees
WHERE salary_rank = 1;
```

### How it works

Suppose we have:

| Name  | Department | Salary |
| ----- | ---------- | -----: |
| Rahul | IT         | 90,000 |
| Amit  | IT         | 80,000 |
| Priya | HR         | 70,000 |
| Neha  | HR         | 65,000 |
| Arjun | IT         | 90,000 |

`PARTITION BY department_id` creates a separate ranking for each department.

`ORDER BY salary DESC` puts the highest salary first.

So the result is:

| Name  | Department | Salary |
| ----- | ---------- | -----: |
| Rahul | IT         | 90,000 |
| Arjun | IT         | 90,000 |
| Priya | HR         | 70,000 |

### Why `DENSE_RANK()`?

Using `DENSE_RANK()` means **all employees tied for the highest salary are returned**.

If you want **exactly one employee per department**, even when salaries are tied, use `ROW_NUMBER()`:

```sql
WITH ranked_employees AS (
    SELECT
        name,
        department_id,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY department_id
            ORDER BY salary DESC, id
        ) AS rn
    FROM employees
)
SELECT
    name,
    department_id,
    salary
FROM ranked_employees
WHERE rn = 1;
```

The `id` provides a deterministic tie-breaker.

### Interview Takeaway

For **highest-paid employee(s) in each department**:

```sql
DENSE_RANK() OVER (
    PARTITION BY department_id
    ORDER BY salary DESC
)
```

Then filter:

```sql
WHERE salary_rank = 1
```

## Answer

A rollback undoes all changes made since the start of the current transaction when an error or failure occurs.

```sql
BEGIN;
UPDATE accounts SET balance = balance - 50 WHERE id = 1;
UPDATE accounts SET balance = balance + 50 WHERE id = 2;
ROLLBACK;
```

### Interview takeaway

Rollback ensures the database remains consistent when business rules or application logic fail.
