## 58. Find employees whose salary is greater than their department's average

### Answer

We need to:

1. Calculate the **average salary for each department**.
2. Compare each employee's salary with their department's average.
3. Return employees whose salary is greater.

### Using a subquery

```sql
SELECT
    e.name,
    e.salary,
    e.department_id
FROM employees e
WHERE e.salary > (
    SELECT AVG(e2.salary)
    FROM employees e2
    WHERE e2.department_id = e.department_id
);
```

### How it works

For every employee, the correlated subquery calculates:

```text
average salary of that employee's department
```

Then:

```sql
e.salary > department_average
```

filters the employees.

For example:

| Employee | Department | Salary | Dept. Average |
| -------- | ---------- | -----: | ------------: |
| Rahul    | IT         | 80,000 |        70,000 |
| Amit     | IT         | 60,000 |        70,000 |
| Priya    | HR         | 65,000 |        55,000 |
| Neha     | HR         | 45,000 |        55,000 |

Result:

```text
Rahul   80000   IT
Priya   65000   HR
```

### Using a CTE

A cleaner approach for more complex queries is:

```sql
WITH department_avg AS (
    SELECT
        department_id,
        AVG(salary) AS avg_salary
    FROM employees
    GROUP BY department_id
)
SELECT
    e.name,
    e.salary,
    e.department_id
FROM employees e
JOIN department_avg d
    ON e.department_id = d.department_id
WHERE e.salary > d.avg_salary;
```

### Interview Takeaway

The key pattern to remember is:

```sql
WHERE salary > (
    SELECT AVG(salary)
    FROM employees
    WHERE department_id = outer_employee.department_id
);
```
