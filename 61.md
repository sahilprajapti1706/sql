
## 61. Find the top 3 products in each category

### Answer

Use a **window function with `ROW_NUMBER()`**.

```sql
WITH ranked_products AS (
    SELECT
        id,
        product_name,
        category_id,
        price,
        ROW_NUMBER() OVER (
            PARTITION BY category_id
            ORDER BY price DESC
        ) AS rn
    FROM products
)
SELECT
    id,
    product_name,
    category_id,
    price
FROM ranked_products
WHERE rn <= 3;
```

### How it works

Suppose the products are:

| Product  | Category    |  Price |
| -------- | ----------- | -----: |
| Laptop A | Electronics | 80,000 |
| Laptop B | Electronics | 70,000 |
| Laptop C | Electronics | 60,000 |
| Laptop D | Electronics | 50,000 |
| Shirt A  | Clothing    |  3,000 |
| Shirt B  | Clothing    |  2,500 |
| Shirt C  | Clothing    |  2,000 |
| Shirt D  | Clothing    |  1,500 |

`PARTITION BY category_id` ranks products **separately within each category**.

`ORDER BY price DESC` puts the highest-priced product first.

Then:

```sql
WHERE rn <= 3
```

returns the top 3 from every category.

### If ties should be included

If two products have the same price and you want **all products within the top 3 ranks**, use `DENSE_RANK()` instead:

```sql
WITH ranked_products AS (
    SELECT
        id,
        product_name,
        category_id,
        price,
        DENSE_RANK() OVER (
            PARTITION BY category_id
            ORDER BY price DESC
        ) AS product_rank
    FROM products
)
SELECT *
FROM ranked_products
WHERE product_rank <= 3;
```

### Interview Takeaway

**Exactly 3 products per category:**

```sql
ROW_NUMBER() OVER (
    PARTITION BY category_id
    ORDER BY price DESC
)
```

**Top 3 ranks including ties:**

```sql
DENSE_RANK() OVER (
    PARTITION BY category_id
    ORDER BY price DESC
)
```

The important pattern is:

**`PARTITION BY` → rank within each group → filter the rank.**
