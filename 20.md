
## 20. What is a FULL OUTER JOIN?

### Answer

A **FULL OUTER JOIN** returns **all rows from both tables**.

* If a row has a matching row in the other table → the data from both tables is combined.
* If a row exists only in the left table → columns from the right table become `NULL`.
* If a row exists only in the right table → columns from the left table become `NULL`.

### Syntax

```sql
SELECT columns
FROM table1 t1
FULL OUTER JOIN table2 t2
    ON t1.id = t2.table1_id;
```

### Example

Suppose we have:

**users**

| id | name  |
| -: | ----- |
|  1 | Sahil |
|  2 | Rahul |
|  3 | Priya |

**orders**

|  id | user_id | amount |
| --: | ------: | -----: |
| 101 |       1 |    500 |
| 102 |       2 |    800 |
| 103 |       4 |    300 |

Here:

* Users `1` and `2` have matching orders.
* User `3` has no order.
* Order `103` belongs to `user_id = 4`, which has no matching user.

```sql
SELECT
    u.id,
    u.name,
    o.id AS order_id,
    o.amount
FROM users u
FULL OUTER JOIN orders o
    ON u.id = o.user_id;
```

Result:

|   id | name  | order_id | amount |
| ---: | ----- | -------: | -----: |
|    1 | Sahil |      101 |    500 |
|    2 | Rahul |      102 |    800 |
|    3 | Priya |     NULL |   NULL |
| NULL | NULL  |      103 |    300 |

### Visual intuition

Think of it as:

```text
        ALL USERS
      ┌─────────────┐
      │  matched    │
      │    rows      │
      └─────────────┘
            +
      users without orders
            +
      orders without users
```

So:

```text
FULL OUTER JOIN
= matching rows
+ left-only rows
+ right-only rows
```

### FULL OUTER JOIN vs other JOINs

| JOIN                | Returns                             |
| ------------------- | ----------------------------------- |
| `INNER JOIN`      | Only matching rows                  |
| `LEFT JOIN`       | All left rows + matching right rows |
| `RIGHT JOIN`      | All right rows + matching left rows |
| `FULL OUTER JOIN` | **All rows from both tables** |

### Important practical use

A FULL OUTER JOIN is useful when you want to **compare two datasets and find both matches and mismatches**.

For example, comparing:

* users in two systems
* records between two databases
* old vs new data
* expected vs actual records

You can identify unmatched records by checking for `NULL` on either side.

### Interview Takeaway

> **FULL OUTER JOIN returns every row from both tables, matching rows where possible and filling unmatched columns with `NULL`.**

The easiest way to remember:

**LEFT → keep left**
**RIGHT → keep right**
**FULL → keep both**
