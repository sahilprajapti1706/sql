
## 62. Calculate month-over-month revenue

### Answer

**Month-over-month (MoM) revenue** compares the revenue of the current month with the previous month.

For example:

| Month |   Revenue | Previous Month | MoM Change |
| ----- | --------: | -------------: | ---------: |
| Jan   | ₹100,000 |             — |         — |
| Feb   | ₹120,000 |      ₹100,000 |   ₹20,000 |
| Mar   |  ₹90,000 |      ₹120,000 |  -₹30,000 |

Assume a `sales` table:

```text
sales
- id
- sale_date
- amount
```

### Using `LAG()`

First calculate monthly revenue, then use `LAG()` to get the previous month's revenue:

```sql
WITH monthly_revenue AS (
    SELECT
        DATE_TRUNC('month', sale_date) AS month,
        SUM(amount) AS revenue
    FROM sales
    GROUP BY DATE_TRUNC('month', sale_date)
)
SELECT
    month,
    revenue,
    LAG(revenue) OVER (
        ORDER BY month
    ) AS previous_month_revenue,
    revenue - LAG(revenue) OVER (
        ORDER BY month
    ) AS revenue_change
FROM monthly_revenue
ORDER BY month;
```

### Calculate MoM percentage

Usually, "month-over-month revenue" means we may also want the **percentage change**:

```sql
WITH monthly_revenue AS (
    SELECT
        DATE_TRUNC('month', sale_date) AS month,
        SUM(amount) AS revenue
    FROM sales
    GROUP BY DATE_TRUNC('month', sale_date)
),
revenue_with_previous AS (
    SELECT
        month,
        revenue,
        LAG(revenue) OVER (
            ORDER BY month
        ) AS previous_month_revenue
    FROM monthly_revenue
)
SELECT
    month,
    revenue,
    previous_month_revenue,
    revenue - previous_month_revenue AS revenue_change,
    ROUND(
        100.0 * (revenue - previous_month_revenue)
        / NULLIF(previous_month_revenue, 0),
        2
    ) AS mom_percentage
FROM revenue_with_previous
ORDER BY month;
```

### Example result

```text
month       revenue    previous    change     mom %
----------  ---------  ----------  ---------  ------
2026-01     100000     NULL        NULL       NULL
2026-02     120000     100000      20000      20.00
2026-03     90000      120000      -30000     -25.00
```

The formula is:

```text
MoM % = (Current Month Revenue - Previous Month Revenue)
        / Previous Month Revenue × 100
```

### Why `LAG()`?

`LAG()` allows us to access a value from the **previous row** without joining the table to itself.

After monthly aggregation:

```text
Jan → 100,000
Feb → 120,000
Mar → 90,000
```

`LAG(revenue)` produces:

```text
Jan → NULL
Feb → 100,000
Mar → 120,000
```

So each month's revenue can be compared directly with the previous month.

### Interview Takeaway

The key pattern is:

```sql
LAG(revenue) OVER (ORDER BY month)
```

For a complete MoM calculation:

**`GROUP BY month → SUM(revenue) → LAG() → calculate percentage change`**

Also remember `NULLIF(previous_month_revenue, 0)` prevents a division-by-zero error when the previous month's revenue is zero.
