## 12. What are aggregate functions?

### Answer

**Aggregate functions** are SQL functions that take **multiple rows as input and return a single summarized value**.

They are mainly used to perform calculations such as:

* Counting rows
* Finding totals
* Finding averages
* Finding minimum/maximum values

The most commonly used aggregate functions are:

| Function    | Purpose             |
| ----------- | ------------------- |
| `COUNT()` | Counts rows/values  |
| `SUM()`   | Calculates total    |
| `AVG()`   | Calculates average  |
| `MIN()`   | Finds minimum value |
| `MAX()`   | Finds maximum value |

---

## Example

Suppose we have an `employees` table:

| id | name  | department | salary |
| -: | ----- | ---------- | -----: |
|  1 | Sahil | IT         |  50000 |
|  2 | Rahul | HR         |  35000 |
|  3 | Priya | IT         |  65000 |
|  4 | Ankit | Sales      |  45000 |
|  5 | Neha  | HR         |  55000 |

### 1. `COUNT()`

Count the number of employees:

```sql
SELECT COUNT(*) AS total_employees
FROM employees;
```

Result:

```text
total_employees
---------------
5
```

You can also count a particular column:

```sql
SELECT COUNT(salary)
FROM employees;
```

`COUNT(salary)` counts non-`NULL` salary values, whereas `COUNT(*)` counts rows.

---

### 2. `SUM()`

Calculate the total salary:

```sql
SELECT SUM(salary) AS total_salary
FROM employees;
```

Result:

```text
250000
```

---

### 3. `AVG()`

Calculate the average salary:

```sql
SELECT AVG(salary) AS average_salary
FROM employees;
```

Result:

```text
50000
```

---

### 4. `MIN()`

Find the lowest salary:

```sql
SELECT MIN(salary) AS minimum_salary
FROM employees;
```

Result:

```text
35000
```

---

### 5. `MAX()`

Find the highest salary:

```sql
SELECT MAX(salary) AS maximum_salary
FROM employees;
```

Result:

```text
65000
```

---

# Aggregate Functions with `GROUP BY`

This is where aggregate functions become especially useful.

For example, find the **number of employees in each department**:

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department;
```

Result:

| department | employee_count |
| ---------- | -------------: |
| IT         |              2 |
| HR         |              2 |
| Sales      |              1 |

Similarly, find the average salary for each department:

```sql
SELECT department, AVG(salary) AS average_salary
FROM employees
GROUP BY department;
```

Result:

| department | average_salary |
| ---------- | -------------: |
| IT         |          57500 |
| HR         |          45000 |
| Sales      |          45000 |

### Mental Model

Without `GROUP BY`:

```text
All rows
   ↓
Aggregate function
   ↓
One result
```

With `GROUP BY`:

```text
All rows
   ↓
Split into groups
   ↓
Aggregate each group
   ↓
One result per group
```

---

# Aggregate Functions with `HAVING`

Since `HAVING` filters groups, it is commonly used with aggregate functions.

For example, find departments with more than one employee:

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department
HAVING COUNT(*) > 1;
```

Result:

| department | employee_count |
| ---------- | -------------: |
| IT         |              2 |
| HR         |              2 |

Here:

* `GROUP BY` creates department groups.
* `COUNT()` counts employees in each group.
* `HAVING` filters those groups.

## Important: `COUNT(*)` vs `COUNT(column)`

This is a common interview question.

Suppose:

| id | name | salary |
| -: | ---- | -----: |
|  1 | A    |  50000 |
|  2 | B    |   NULL |
|  3 | C    |  40000 |

```sql
SELECT COUNT(*)
FROM employees;
```

returns:

```text
3
```

because `COUNT(*)` counts **rows**.

But:

```sql
SELECT COUNT(salary)
FROM employees;
```

returns:

```text
2
```

because `COUNT(salary)` counts only rows where `salary` is **not `NULL`**.

---

## Important: Aggregate Functions and `NULL`

Most aggregate functions ignore `NULL` values.

For example:

```sql
SELECT AVG(salary)
FROM employees;
```

does not treat a `NULL` salary as `0`; that row is excluded from the average calculation.

This distinction matters because:

```text
NULL ≠ 0
```

If you explicitly want to treat `NULL` as zero, you can use `COALESCE()`:

```sql
SELECT AVG(COALESCE(salary, 0))
FROM employees;
```

But whether this is correct depends on the meaning of the data.

## Real-World Uses

Aggregate functions are heavily used in reporting and analytics:

```sql
-- Total revenue
SELECT SUM(amount)
FROM orders;

-- Number of orders
SELECT COUNT(*)
FROM orders;

-- Average order value
SELECT AVG(amount)
FROM orders;

-- Highest transaction
SELECT MAX(amount)
FROM transactions;

-- Revenue by month/category/customer
SELECT customer_id, SUM(amount)
FROM orders
GROUP BY customer_id;
```

They are especially important for **dashboards, reports, business analytics, and ML data exploration**.

---

### Interview Takeaway

> **Aggregate functions summarize multiple rows into a calculated result.**

Remember:

```text
COUNT → How many?
SUM   → How much in total?
AVG   → What's the average?
MIN   → What's the smallest?
MAX   → What's the largest?
```

And the key relationship:

**`GROUP BY` creates groups → aggregate functions calculate values for those groups → `HAVING` can filter those groups**

## Answer

`GROUP BY` groups rows that share the same value in a column. It is commonly used with aggregate functions to compute totals, averages, and counts per category.

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department;
```

### Interview takeaway

Without `GROUP BY`, aggregate functions would return a single value for the whole table rather than per group.
