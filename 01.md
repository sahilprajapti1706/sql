# 1. What is SQL and what is it used for?

## Answer

**SQL (Structured Query Language)** is a standard language used to **interact with relational databases**. It allows us to create, read, update, and delete data, as well as define the structure of databases and control access to them.

SQL is used with relational database systems such as **PostgreSQL, MySQL, Microsoft SQL Server, Oracle Database, and SQLite**.

### Why do we need SQL?

Applications usually need to store persistent data?for example:

* Users and their profiles
* Products and orders
* Student records
* Transactions
* ML training data and prediction results

Instead of keeping all this data in application memory, a relational database stores it in structured **tables**. SQL provides a standardized way for an application or developer to query and manage that data.

---

## What can SQL do?

SQL is commonly used for the following operations:

| Purpose                   | SQL capability       | Example                         |
| ------------------------- | -------------------- | ------------------------------- |
| Read data                 | `SELECT`             | Find all users                  |
| Insert data               | `INSERT`             | Create a new user               |
| Modify data               | `UPDATE`             | Change a user's email           |
| Delete data               | `DELETE`             | Remove a record                 |
| Create tables             | `CREATE TABLE`       | Define a users table            |
| Modify database structure | `ALTER TABLE`        | Add a new column                |
| Delete database objects   | `DROP`               | Remove a table                  |
| Combine data              | `JOIN`               | Combine users with their orders |
| Aggregate data            | `GROUP BY`           | Count orders per user           |
| Control transactions      | `COMMIT`, `ROLLBACK` | Safely handle multiple changes  |

### Simple example

Suppose we have a `users` table:

```text
users
+----+----------+-------------------+
| id | name     | email             |
+----+----------+-------------------+
| 1  | Sahil    | sahil@example.com  |
| 2  | Rahul    | rahul@example.com  |
+----+----------+-------------------+
```

To retrieve users whose name is Sahil:

```sql
SELECT id, name, email
FROM users
WHERE name = 'Sahil';
```

The database executes the query and returns the matching rows.

---

## SQL is more than just querying data

SQL is often described as a **query language**, but it also provides mechanisms for:

### 1. Data Definition

Define the structure of database objects:

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(255)
);
```

### 2. Data Manipulation

Modify the data:

```sql
INSERT INTO users (id, name, email)
VALUES (1, 'Sahil', 'sahil@example.com');
```

```sql
UPDATE users
SET email = 'new@example.com'
WHERE id = 1;
```

### 3. Data Retrieval

Query data:

```sql
SELECT *
FROM users
WHERE id = 1;
```

### 4. Transaction Management

Transactions allow multiple operations to be treated as a logical unit.

For example, transferring ?1,000 between two bank accounts should not leave the database in a partially updated state.

```sql
BEGIN;

UPDATE accounts
SET balance = balance - 1000
WHERE id = 1;

UPDATE accounts
SET balance = balance + 1000
WHERE id = 2;

COMMIT;
```

If something goes wrong, the transaction can be rolled back rather than leaving inconsistent data.

## SQL and relational databases

SQL is primarily associated with **relational databases**, where data is organized into tables containing rows and columns.

Tables can be related using keys.

For example:

```text
users
id | name

orders
id | user_id | amount
```

Here, `orders.user_id` can reference `users.id`.

We can retrieve information from both tables using a `JOIN`:

```sql
SELECT users.name, orders.amount
FROM users
JOIN orders
    ON users.id = orders.user_id;
```

This is one of the major strengths of relational databases: **SQL can retrieve and combine related data declaratively without requiring the application to manually iterate through tables.**

## SQL in a real application

Consider a backend application built with **Node.js + PostgreSQL**.

A typical flow might be:

```text
User
  ?
Frontend
  ?
Backend API
  ?
SQL Query
  ?
PostgreSQL
  ?
Result
  ?
Backend
  ?
Frontend
```

For example, when a user logs into an application, the backend might execute a parameterized query such as:

```sql
SELECT id, name, email
FROM users
WHERE email = $1;
```

The application supplies the actual email as a parameter.

Using parameters is important because constructing SQL by directly concatenating user input can lead to **SQL injection**.

For example, a recommendation system might need:


The resulting data could then be used for:

## Important distinction: SQL vs PostgreSQL

A common interview mistake is treating SQL and a database system as the same thing.

* **SQL** ? the language used to interact with relational databases.
* **PostgreSQL** ? a relational database management system (RDBMS) that implements SQL and provides additional database-specific features.
* **MySQL** ? another RDBMS that supports SQL.

So you can think of it as:

```text
SQL = Language
PostgreSQL / MySQL / Oracle = Database systems that use the language
```

Different database systems may support SQL features differently or provide their own extensions.

---

## Common Mistakes

**1. "SQL is a database."**
No. SQL is a language. PostgreSQL, MySQL, and Oracle Database are database systems.

**2. "SQL is only used to retrieve data."**
No. SQL can also create database structures, insert/update/delete data, manage transactions, and perform other database operations.

**3. "SQL and NoSQL are completely unrelated languages."**
SQL refers to a database language primarily used with relational systems, while NoSQL is a broader category of non-relational database systems. Some NoSQL databases may provide their own query languages or APIs.

**4. Writing SQL using string concatenation with user input.**
This can create SQL injection vulnerabilities. Prefer **parameterized queries/prepared statements**.

---

## Interview Takeaway

* **SQL is a standard language for interacting with relational databases.**
* It is used to **query, insert, update, delete, and define structured data**.
* SQL is especially powerful for **filtering, joining, aggregating, and managing related data**.
* In real applications, SQL commonly sits between the **backend application and relational database**.
* In ML/AI projects, SQL is frequently used for **data extraction, preprocessing, analytics, and feature preparation**.
